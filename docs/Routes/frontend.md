# `GET /{*Rest}`

Serves any file of the embedded assets/frontend tree

| Entries | Read from | In | Type | Default | Description |
| --- | --- | --- | --- | --- | --- |
| `Rest` | segments 0..-1 | path | string |  | the file under assets/frontend; none is its index.html |
